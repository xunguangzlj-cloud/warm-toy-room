# 暖光玩具房 · 客厅与庭院

[在线试玩](https://xunguangzlj-cloud.github.io/warm-toy-room/)

从玩具房的花地毯出发，推开写着「客厅」的小木门。你可以带一颗弹珠去探险，也可以随时回玩具房继续收集星光。

## 两段冒险

| 地图 | 主线 |
| --- | --- |
| 客厅 · 午后的钟声 | 跳上脚凳取下黄铜发条，装进落地钟，再从沙发上拉响报时绳。 |
| 庭院 · 风铃花圃 | 转动水泵手轮，沿水渠提起木闸，最后摇响花架下的风铃。 |

靠近门牌，按 **E** 开门，然后朝门洞里走。手机点 **互动**，再推摇杆穿过门槛。两条主线可以交错进行，拿在手里的玩具也能一起过门。

电脑使用 **WASD** 移动、**空格** 跳跃。手机建议横屏，首次打开时，游戏会按显卡支持的格式下载贴图。常见组合约需 213 至 236 MB，兼容模式最多约 290 MB。浏览器保留完整缓存后，再次打开可以直接读取本机资源。

## 项目文件

`docs/` 是可直接托管的网页游戏，`extension/` 收录扩展地图的 Godot 场景、脚本、着色器和美术资源。下载仓库后，可在仓库目录运行 `python -m http.server 8000 --directory docs`，再打开 `http://localhost:8000/` 试玩。
